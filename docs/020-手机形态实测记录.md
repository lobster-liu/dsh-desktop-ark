> 结论：**在本机跑通**，含对话。但上游规范禁止声明 phone（见「与上游规范的冲突」），故本次仅作为可行性记录，不改变产品形态。

## 二、让它装上的改动

只改了一行 —— `entry/src/main/module.json5` 的 `deviceTypes` 增加 `"phone"`：

```json5
"deviceTypes": [
  "2in1",
  "tablet",
  "phone"
],
```

不改这一行时，系统在安装阶段直接拒绝：

```
code:9568413  device type is not supported
```

## 三、与上游规范的冲突（重要）

本工程的设计规范明确禁止 phone 形态：

- `specs/103-*/spec.md` **FR-103-002**：应用 MUST 只声明 2in1 与 tablet；MUST NOT 声明 phone。
- `specs/108-*/spec.md` **FR-108-002**：设备形态 MUST 仅包含 2in1 与 tablet；MUST NOT 声明 phone。
- `docs/000-工程规划.md`：明确"不做 phone 形态"。

因此这一行改动**是有意偏离上游规范**。是否合并需要维护者决定：

- 若只为记录可行性 → 保留本文档，不合并 `deviceTypes` 改动；
- 若要正式支持手机 → 需要同步修改上述两条 FR、能力清单与 ACL 文档。

## 四、未验证 / 已知限制

- **流式与非流式**：仅验证了非流式对话（`--jitless` 下 SSE 由纯 JS 垫片提供，自检覆盖了 SSE 三帧，但真实模型的长流式回复未做长时段压测）。
- **性能**：`--jitless` 为解释执行，参考姊妹工程真机数据，热循环约 7–10×、图片重编码约 15× 慢。本次未做基准。
- **插件市场**：`dshmarket` 已随包且 `pnpm` 引擎已物化，但**未在手机上下载安装过插件**，故「市场安装」在 phone 上未取证。
- **命令执行**：`shell` 走 `/system/bin/sh`，未在 phone 上执行过命令。
- **工作区「文档 / 下载」**：仅验证了「沙箱」根；另两个根需用户授权，未实测。
- **返回手势 / 长时任务**：未做长时间后台存活验证。

## 五、复现步骤

前置：DevEco Studio（含 SDK）、Node 18+、pnpm、已连接且开启 USB 调试的手机。

```bash
# 1) 物化载荷（需要同级的 ../deepseek-harness 与 ../dsh-market）
node scripts/assemble-payload.mjs --deploy --apply

# 2) 打包载荷
node scripts/package-payload.mjs

# 3) 构建 HAP（务必用 DevEco 自带 JBR 跑签名，否则报 11012006）
bash scripts/build-hap.sh --debug --node-mode compat

# 4) 装机并启动
hdc -t <serial> install -r entry/build/default/outputs/default/entry-default-signed.hap
hdc -t <serial> shell aa start -a EntryAbility -b top.fellow99.dsh.DshDesktopArk
```

若构建阶段报 `00303116`（`storePassword` 长度 < 32），说明签名配置里写了明文密码——hvigor 只接受 DevEco 加密串。此时可让 hvigor 只产 unsigned，再用 `hap-sign-tool` 手动签名：

```bash
java -jar "$SDK/toolchains/lib/hap-sign-tool.jar" sign-app \
  -mode localSign -keyAlias <alias> \
  -appCertFile <cert> -profileFile <profile.p7b> \
  -inFile entry-default-unsigned.hap -outFile entry-default-signed.hap \
  -signAlg SHA256withECDSA -keystoreFile <store.p12> \
  -compatibleVersion 17 -signCode 1 \
  -keystorePwd <pwd> -keyPwd <pwd>
```

验证运行态：

```bash
hdc -t <serial> shell cat /data/app/el2/100/base/top.fellow99.dsh.DshDesktopArk/haps/entry/files/payload/ready.json
hdc -t <serial> shell snapshot_display -f /data/local/tmp/s.jpeg
```
